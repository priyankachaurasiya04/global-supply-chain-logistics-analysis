# 🚚 Global Supply Chain Logistics Analysis

## 📌 Overview
Data Analytics project focused on analyzing delivery performance, delay risk, and logistics efficiency using **180,519 orders**.

## 🎯 Objectives
- Analyze delivery performance
- Identify shipment delays
- Measure late-delivery risk
- Compare shipping modes
- Identify high-risk regions and countries
- Analyze customer segments

## 🛠️ Tools
- Python (Pandas, NumPy, Matplotlib, Seaborn, Plotly)
- Tableau
- Excel

## 📊 Key Findings
- 57.28% of orders were delayed
- Late-delivery risk was 54.83%
- Second Class had the highest average delay: 1.99 days
- Central Africa had the highest regional risk: 57.96%
- Ecuador had the highest country-level risk: 67.01%

## 📈 Dashboard
Interactive Tableau dashboard covering delivery performance, delay risk, shipping modes, regions, and customer segments.
